# ไฟล์ประกอบหนังสือ n8n เล่ม 2: AI Agent ในองค์กร

ไฟล์ประกอบของหนังสือ "n8n เล่ม 2: AI Agent ในองค์กร" โดย ดร.อาณัติ รัตนถิรกุล (SysAdmin Knowledge Press) มี workflow JSON 43 ไฟล์ ไฟล์ Docker Compose ของห้องทดลอง SQL ข้อมูลตัวอย่าง ชุดทดสอบ และเอกสารสมมุติที่ใช้ในเล่ม

ทุกไฟล์ทดสอบบน n8n 2.43.7 กับโมเดลที่รันในเครื่องผ่าน Ollama ข้อมูลทุกชิ้นเป็นข้อมูลสมมุติ ไม่มีข้อมูลบุคคลหรือหน่วยงานจริง

## โครงโฟลเดอร์

```
lab/          ไฟล์ Docker Compose ของห้องทดลอง และไฟล์เสริมของแต่ละบท
workflows/    ไฟล์ workflow JSON นำเข้า n8n ได้ทันที (43 ไฟล์)
data/         SQL สร้างตารางพร้อมข้อมูลตัวอย่าง และชุดทดสอบของแต่ละบท
kb/           เอกสารสมมุติของเทศบาลเมืองบ้านสวน 5 ฉบับ (บทที่ 6 และ 8)
kb-pdf/       เอกสารภาษีที่ดินฉบับ PDF สองฟอนต์ (บทที่ 6)
kb-siampart/  คู่มือสินค้าสมมุติของสยามพาร์ท 5 ฉบับ (บทที่ 10)
invoices/     ใบแจ้งหนี้สมมุติ 6 ใบ ภาพสแกน 1 ภาพ และ expected.json (บทที่ 11)
scripts/      สคริปต์ทดสอบและสคริปต์สำรองข้อมูล
```

## เริ่มต้น

```
git clone https://github.com/arnutkmitl/n8n-book-vol2.git
cd n8n-book-vol2/lab
cp .env.example .env
```

แก้ค่าใน `.env` ทุกบรรทัดก่อนรัน ตั้งรหัสผ่านฐานข้อมูลใหม่ และสร้าง `N8N_ENCRYPTION_KEY` ด้วย `openssl rand -hex 32` จากนั้นทำตามบทที่ 2 ของหนังสือ

วิธีนำเข้า workflow ชื่อ Credential ที่แต่ละไฟล์อ้างถึง และลำดับรัน SQL อยู่ในภาคผนวก ฉ ของหนังสือ

## สิ่งที่ไม่อยู่ใน repo นี้

ไฟล์ `.env` รหัสผ่าน API key และ token ทุกชนิด ผู้อ่านต้องสร้างเองทุกค่า ห้าม commit ไฟล์ `.env` ของตนขึ้น repo สาธารณะ ไฟล์ `.gitignore` กันไว้ให้แล้ว
